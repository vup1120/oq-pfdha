# Configuration File Guide

All public PFDHA calculations are controlled by a **INI** job file. The INI file defines the run geometry and calculation controls, and it points to two XML logic trees:

- `source_model_logic_tree_file`: the OpenQuake-style source-model logic tree.
- `fdha_logic_tree_file`: the FDHA model logic tree.

The public INI file must not contain `source_model_file`, `fdha_logic_tree_files`, or any `[models]` / `[models.*]` sections. The current loader rejects those legacy public keys. Model selections and model parameters are defined inside the FDHA logic-tree XML.

!!! info "Internal branch INIs"
    During logic-tree execution, the driver materializes internal branch INI files under `branch_configs/`. Those internal files may contain `[models.*]` sections because they are generated by the driver for one end-branch. Do not use that layout for user-facing job files.

---

## File Structure Overview

The public INI file uses these sections:

- **`[general]`**: Optional metadata.
- **`[geometry]`**: Single point-site definition for a hazard curve, or region/grid definition for a hazard map. Required.
- **`[erf]`**: Rupture conversion parameters. Optional keys have defaults.
- **`[calculation]`**: Logic-tree file paths, displacement levels, and calculation options. Required.
- **`[site_params]`**: Optional site parameters such as Vs30.

The calculation type is detected from `[geometry]`: a `region` key means hazard map; otherwise the run is treated as hazard curve.

---

## Units and Conventions

| Parameter | Unit / convention |
| :--- | :--- |
| `sites`, `region` | Longitude latitude order, decimal degrees |
| `region_grid_spacing` | Decimal degrees |
| `rupture_mesh_spacing`, `max_distance_km`, `r_threshold_km`, `near_far_threshold_km` | Kilometers |
| `displacement_measure_levels` | Meters |
| `return_period`, `investigation_time` | Years |

---

## `[calculation]`

| Parameter | Type | Default | Required? | Description |
| :--- | :--- | :--- | :--- | :--- |
| `source_model_logic_tree_file` | string | none | **Yes** | Path to the source-model logic-tree XML wrapper. Relative paths are resolved from the INI directory by the logic-tree driver. |
| `fdha_logic_tree_file` | string | none | **Yes** | Path to the FDHA logic-tree XML. This is singular; the legacy plural `fdha_logic_tree_files` is rejected. |
| `displacement_measure_levels` | JSON dict | none | **Yes** | Target displacement levels. The supported public shape is `{"FD": [0.001, 0.01, ...]}`. |
| `investigation_time` | float | `1.0` | No | Investigation time in years. |
| `return_period` | float | `100000.0` | Hazard map only | Return period used to invert each site hazard curve into map displacement. |
| `max_distance_km` | float | `10.0` | Hazard map optional | Maximum distance from fault traces used when building hazard-map sites. The loader also accepts this in `[geometry]`. |
| `r_threshold_km` | float | implementation default | No | Distance threshold used by hazard calculations to separate principal/near-trace behavior where applicable. |
| `near_far_threshold_km` | float | implementation default | No | Copied into runtime parameters when supplied. |
| `rank1p5_traces_file` | string | none | No | Optional XML file of rank-1.5 traces. If the file exists and parses, traces are added to runtime configuration. |

Example:

```ini
[calculation]
investigation_time = 1.0
displacement_measure_levels = {"FD": [0.0001, 0.001, 0.01, 0.1, 1.0]}
r_threshold_km = 0.1
fdha_logic_tree_file = hazard_curve_minimal_fdha_logic_tree.xml
source_model_logic_tree_file = hazard_curve_minimal_source_model_logic_tree.xml
```

!!! warning "Rejected legacy keys"
    `source_model_file` is no longer a public INI key. Wrap source XML files in `source_model_logic_tree_file` instead. The old `[models.*]` INI sections are also rejected in public jobs.

## `[geometry]`

### Hazard Curve Sites

A hazard-curve job uses one or more point sites. Provide them either inline
with `sites` or from a CSV file with `sites_csv` (give exactly one of the two).

| Parameter | Type | Required? | Description |
| :--- | :--- | :--- | :--- |
| `sites` | string | One of `sites` / `sites_csv` | One or more `lon lat [depth]` entries, comma-separated: `lon1 lat1, lon2 lat2, ...`. Depth (km) is optional and per-site. |
| `sites_csv` | string | One of `sites` / `sites_csv` | Path (relative to the INI file) to a CSV whose header contains `lon` and `lat` columns (case-insensitive), and an optional `depth` column. |

Longitude must be in the range (-180, 360] and latitude in [-90, 90]; values
outside these ranges raise a configuration error.

```ini
# Single site
[geometry]
sites = 16.16573727 39.64704451
```

```ini
# Multiple sites
[geometry]
sites = 16.16573727 39.64704451, 16.20 39.66, 16.24 39.68
```

```ini
# Sites from a CSV file (header: site_id,lon,lat[,depth])
[geometry]
sites_csv = my_sites.csv
```

### Hazard Map Region

| Parameter | Type | Default | Required? | Description |
| :--- | :--- | :--- | :--- | :--- |
| `region` | string | none | **Yes** | Comma-separated `lon lat` corners defining the grid region. |
| `region_grid_spacing` | float | `0.1` in logic-tree map driver | No | Grid spacing in decimal degrees. Examples use `0.01`. |
| `max_distance_km` | float | `10.0` | No | Maximum distance from fault traces. May also be placed in `[calculation]`. |

```ini
[geometry]
region = 15.9 39.2, 16.3 39.2, 16.3 39.8, 15.9 39.8
region_grid_spacing = 0.01
```

## `[erf]`

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `rupture_mesh_spacing` | float | `0.5` in the config dataclass; examples use `2.0` | Fault-surface rupture mesh spacing in kilometers. |
| `width_of_mfd_bin` | float | `0.1` | MFD bin width in magnitude units. |

```ini
[erf]
rupture_mesh_spacing = 2.0
width_of_mfd_bin = 0.1
```

---

## `[site_params]`

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `reference_vs30_value` | float | `760.0` when runtime defaults are used | Vs30 in m/s. The loader copies this to runtime `site_location.vs30` when present. |
| `reference_vs30_type` | string | not normalized by the loader | Metadata retained in config. |
| `reference_depth_to_1pt0km_per_sec` | float | not normalized by the loader | Metadata retained in config. |
| `reference_depth_to_2pt5km_per_sec` | float | not normalized by the loader | Metadata retained in config. |

The hazard-map driver reads the normalized Vs30 from `site_location.vs30`. Use `reference_vs30_value` for the public INI path.

```ini
[site_params]
reference_vs30_value = 760.0
```

## FDHA Logic Tree XML

The FDHA logic tree selects the four model categories:

| Uncertainty type | Runtime slot |
| :--- | :--- |
| `fdhaPrimarySRModel` | `primary_surf_rup` |
| `fdhaPrimaryFDModel` | `primary_surf_displ` |
| `fdhaSecondarySRModel` | `secondary_surf_rup` |
| `fdhaSecondaryFDModel` | `secondary_surf_displ` |

Each branch's `<uncertaintyModel>` text is an INI-like block. The first bracketed name is the model class; following lines are model parameters.

```xml
<logicTreeBranchSet branchSetID="bs_1_primary_surf_rup"
                    uncertaintyType="fdhaPrimarySRModel">
  <logicTreeBranch branchID="B1_PRIMARY_SURF_RUP">
    <uncertaintyModel><![CDATA[[Youngs2003PrimarySR]
style = all]]></uncertaintyModel>
    <uncertaintyWeight>1.0</uncertaintyWeight>
  </logicTreeBranch>
</logicTreeBranchSet>
```

Supported FDHA branch-set filters in the parser/validator are:

- `applyToSources`
- `applyToBranches`
- `applyToStyle`, with allowed values `strike-slip`, `reverse`, or `normal`

Validator checks include supported uncertainty types, weight sums of 1.0 per branch set, valid `applyToBranches` references, valid source IDs when available, registered model classes, and advisory warnings for mixed primary displacement definitions where citation-traced metadata exists.

## Source-Model Logic Tree XML

The source-model logic tree is parsed with OpenQuake hazardlib's `SourceModelLogicTree`. The first branch set must be `uncertaintyType="sourceModel"` and points to one or more source-model XML files.

Minimal wrapper:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<nrml xmlns="http://openquake.org/xmlns/nrml/0.4">
  <logicTree logicTreeID="lt_sm_example">
    <logicTreeBranchSet uncertaintyType="sourceModel" branchSetID="bs_sm">
      <logicTreeBranch branchID="b_sm">
        <uncertaintyModel>source_model.xml</uncertaintyModel>
        <uncertaintyWeight>1.0</uncertaintyWeight>
      </logicTreeBranch>
    </logicTreeBranchSet>
  </logicTree>
</nrml>
```

The source-model logic-tree path supports the OpenQuake source-model uncertainty types recognized by hazardlib, including alternative `sourceModel` branches and supported MFD, geometry, depth, magnitude-scaling-relation, and dummy uncertainties.

## Complete Examples

### Minimal Hazard Curve

```ini
[general]
description = minimal_hazard_curve
calculation_mode = fdha_classical

[geometry]
sites = 16.16573727 39.64704451

[erf]
rupture_mesh_spacing = 2.0
width_of_mfd_bin = 0.1

[calculation]
investigation_time = 1.0
displacement_measure_levels = {"FD": [0.0001, 0.001, 0.005, 0.01, 0.015, 0.03, 0.05, 0.075, 0.1, 0.15, 0.3, 0.5, 0.75, 1.0, 3.0, 5.0, 7.5, 10.0]}
r_threshold_km = 0.1
fdha_logic_tree_file = hazard_curve_minimal_fdha_logic_tree.xml
source_model_logic_tree_file = hazard_curve_minimal_source_model_logic_tree.xml
```

### Minimal Hazard Map

```ini
[general]
description = Minimal Hazard Map Example
calculation_mode = fdha_classical

[geometry]
region = 15.9 39.2, 16.3 39.2, 16.3 39.8, 15.9 39.8
region_grid_spacing = 0.01

[erf]
rupture_mesh_spacing = 2.0
width_of_mfd_bin = 0.1

[calculation]
investigation_time = 1.0
displacement_measure_levels = {"FD": [0.0001, 0.001, 0.005, 0.01, 0.015, 0.03, 0.05, 0.075, 0.1, 0.15, 0.3, 0.5, 0.75, 1.0, 3.0, 5.0, 7.5, 10.0]}
return_period = 100000.0
max_distance_km = 10.0
fdha_logic_tree_file = hazard_map_minimal_fdha_logic_tree.xml
source_model_logic_tree_file = hazard_map_minimal_source_model_logic_tree.xml
```
