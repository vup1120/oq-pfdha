# Configuration guide for Moss et al. (2022) — Secondary models

Reference: Moss, R., Thompson, S., Kuo, C.-H., Younesi, K., and Baumont, D. (2022). Reverse Fault PFDHA. Report GIRS-2022-05 (Revised 1/17/2024). DOI: 10.34948/N3F595

## Secondary Surface Rupture: `Moss2022SecondarySR`

Probability of nonzero distributed displacement P(d > 0) at distance `r` from the principal fault trace on reverse faults.

### Model selection

In public jobs, select this class inside an FDHA logic-tree branch with `uncertaintyType="fdhaSecondarySRModel"`.

### Parameters

| Name | Type | Default | Allowed | Description |
| --- | --- | --- | --- | --- |
| `method` | string | `"simple"` | `"simple"`, `"biexp"` | `"simple"`: Eq. 5.5 / Table 5.3 (85th pct, 500 m grid). `"biexp"`: Eqs 5.6–5.7 / Tables 5.4–5.5 (magnitude-binned biexponential CDF). |

### Notes

- **Unit convention:** The adapter passes `r` in kilometres (`ctx.r`). Eq. 5.5 and Eq. 5.8 use kilometres directly; the `biexp` method converts to metres internally for Eq. 5.7.
- **HW/FW determination:** Based on `rx` sign (positive = hanging wall).
- **Biexponential method:** Requires magnitude. No FW coefficients exist for M < 6.0.

## Secondary Surface Displacement: `Moss2022SecondaryFD`

Distributed displacement exceedance probability P(d_secondary > d₀) at distance `r`.

### Model selection

In public jobs, select this class inside an FDHA logic-tree branch with `uncertaintyType="fdhaSecondaryFDModel"`.

### Parameters

| Name | Type | Default | Allowed | Description |
| --- | --- | --- | --- | --- |
| `version` | string | `"MD"` | `"AD"`, `"MD"` | Normalized displacement type. |
| `completeness` | string | `"complete"` | `"complete"`, `"incomplete"` (MD only), `"all"` | Dataset subset for magnitude scaling (Table 4.4). |
| `sigma_type` | string | `"recommended"` | `"recommended"`, `"regression"` | Sigma source for the MD/AD scaling relation. |
| `faulting` | string | `"simple"` | `"simple"`, `"complex"` | Fault complexity category for envelope coefficients. |
| `percentile` | string | `"85"` | `"50"`, `"85"` | Envelope percentile (Tables 5.7–5.8). |
| `method` | string | `"gamma"` | `"gamma"`, `"envelope"` | `"gamma"`: gamma-distributed d/MD scaled by distance envelope, integrated over MD uncertainty. `"envelope"`: deterministic d/MD envelope comparison. |

### Notes

- **Gamma method:** Uses the global gamma shape (Eqs 4.2–4.3) with mean rescaled to the distance-dependent envelope value (Eq. 5.8). Integrated over MD uncertainty identically to the primary FD model.
- **Envelope method:** Assumes d_secondary = MD × envelope(r) deterministically, then computes P(MD × envelope > d₀) via the normal CDF of log₁₀(MD).
- **Unit convention:** The adapter passes `r` in kilometres (`ctx.r`), matching the envelope equations.

### Example FDHA logic-tree branches

```xml
<logicTreeBranchSet branchSetID="bs_secondary_sr"
                    uncertaintyType="fdhaSecondarySRModel">
  <logicTreeBranch branchID="B_MOSS2022_SECONDARY_SR">
    <uncertaintyModel>
      [Moss2022SecondarySR]
      method = simple
    </uncertaintyModel>
    <uncertaintyWeight>1.0</uncertaintyWeight>
  </logicTreeBranch>
</logicTreeBranchSet>

<logicTreeBranchSet branchSetID="bs_secondary_fd"
                    uncertaintyType="fdhaSecondaryFDModel">
  <logicTreeBranch branchID="B_MOSS2022_SECONDARY_FD">
    <uncertaintyModel>
      [Moss2022SecondaryFD]
      version = MD
      completeness = complete
      sigma_type = recommended
      faulting = simple
      percentile = 85
      method = gamma
    </uncertaintyModel>
    <uncertaintyWeight>1.0</uncertaintyWeight>
  </logicTreeBranch>
</logicTreeBranchSet>
```
