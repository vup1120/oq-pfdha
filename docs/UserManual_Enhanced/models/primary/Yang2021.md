# Configuration guide for Yang et al. (2021)

Reference: Yang, H., Quigley, M., & King, T. (2021). Surface slip distributions and geometric complexity of intraplate reverse‑faulting earthquakes. GSA Bulletin, 133(9–10), 1909–1929. https://doi.org/10.1130/B35809.1

The Yang et al. (2021) primary surface rupture model predicts the probability of surface rupture for reverse faulting earthquakes. This model was developed using Australian earthquake data and uses a logistic regression formula.

## Model selection keys

| Path | Required? | Allowed values | Purpose |
| --- | --- | --- | --- |
| `models.primary_surf_rup.type` | Yes | `Yang2021PrimarySR` | Chooses the Yang (2021) surface rupture probability model. |

## Scope and behavior

- **Supported fault styles:** Reverse only
- **Magnitude range:** (see model calibration range in paper)
- **Geographic region:** Developed using Australian earthquake data
- **Statistical distribution:** Logistic regression
- **Classification:** Primary Surface Rupture

## Parameters (`models.primary_surf_rup.parameters`)

This model does not require any additional parameters beyond the model type selection. The probability is computed solely from the earthquake magnitude.

### Runtime inputs

- `mag`: Earthquake magnitude (sourced from each rupture in the input source model at run-time)

## Implementation details

### Logistic regression formula

The model uses a logistic regression to compute surface rupture probability:

```python
fx = -24.59 + 4.0 * mag
prob = exp(fx) / (1.0 + exp(fx))
```

Where:
- `mag` is the moment magnitude
- `fx` is the linear predictor
- `prob` is the surface rupture probability (bounded between 0 and 1)

### Output

The model returns a probability value between 0 and 1:
- For scalar magnitude input: returns a float
- For array-like magnitude input: returns an array of probabilities

## Notes and cautions

- **Style limitation:** This model is designed specifically for reverse faulting earthquakes. Using it for other fault styles may produce invalid results.
- **Geographic calibration:** The model was developed using Australian earthquake data. Application to other regions should be done with caution and consideration of regional differences.
- **Magnitude handling:** The model accepts scalar or array-like magnitude inputs. For arrays, it returns an array of probabilities.
- **Probability bounds:** The logistic function ensures probabilities are bounded between 0 and 1.
- **No additional parameters:** Unlike some other models, this model does not require style, dip, or other geometric parameters. The probability depends solely on magnitude.
