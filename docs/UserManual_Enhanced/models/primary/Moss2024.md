# Configuration guide for Moss et al. (2024)

Reference: Moss, R. E. S., et al. (2024). Primary surface fault displacement models for reverse faults. Earthquake Spectra.

The Moss et al. (2024) primary surface displacement model predicts principal surface fault displacement exceedance probabilities for reverse faults using normalized displacement (d/AD or d/MD) with Gamma distribution parameters that vary with along-strike position.

This is the peer-reviewed *Earthquake Spectra* (2024) model. `source="EQS"`
(the default) uses tabulated Table 2 normalized-displacement alpha/beta
parameters. `source="GIRS"` uses the GIRS-2022-05 Figures 4.3-4.4
gamma-parameter regressions instead. Both branches use the same implemented
complete/all AD/MD magnitude-scaling coefficients from Moss et al. (2024)
Table 3 / GIRS-2022-05 Table 4.4. Use `Moss2022PrimaryFD` if you need
`gamma_mode="global"`, the incomplete MD subset, or the `sigma_type` selector.

## Model selection keys

| Path | Required? | Allowed values | Purpose |
| --- | --- | --- | --- |
| `models.primary_surf_displ.type` | Yes | `Moss2024PrimaryFD` | Chooses the Moss (2024) displacement exceedance model. |

## Scope and behavior

- **Supported fault styles:** Reverse only
- **Magnitude range:** 4.7–8.0
- **Displacement metric:** Principal displacement
- **Normalization:** d/AD (average displacement) or d/MD (maximum displacement)
- **Statistical distribution:** Gamma distribution (via numerical integration over log-normal XD)
- **Slip component:** Vertical displacement
- **Classification:** Single Principal

## Parameters (`models.primary_surf_displ.parameters`)

| Name | Type | Units | Default | Allowed | Required? | Description |
| --- | --- | --- | --- | --- | --- | --- |
| `version` | string | - | `"AD"` | `"AD"`, `"MD"` (case-insensitive) | No | Normalized displacement type. `"AD"` uses d/AD (average displacement), `"MD"` uses d/MD (maximum displacement). |
| `source` | string | - | `"EQS"` | `"EQS"`, `"GIRS"` (case-insensitive) | No | Alpha/beta parameter source. `"EQS"` uses piecewise linear interpolation from Table 2 data files. `"GIRS"` uses regression model from GIRS report Figures 4.3-4.4. |
| `completeness` | string | - | `"all"` | `"complete"`, `"all"` (case-insensitive) | No | Reference model subset. `"complete"` uses complete dataset coefficients, `"all"` uses all data coefficients. |

## Notes and cautions

- **Style limitation:** This model is designed specifically for reverse faults only. Using it for other fault styles may produce invalid results.
- **Magnitude validation:** Magnitude must be a scalar value. Array inputs raise `ValueError`.
- **X_L_ratio validation:** X_L_ratio must be between 0 and 1. Values outside this range raise `ValueError`.
- **Data file requirement:** When `source="EQS"`, the CSV data files must be present in the data directory. Missing files will raise errors.
- **Magnitude scaling:** The implemented complete/all AD and MD scaling coefficients are the same in both `source` branches; `source` changes only the normalized-displacement alpha/beta parameters. The scaling coefficients are from Moss et al. (2024) Table 3 / GIRS-2022-05 Table 4.4, not Table 2.
- **Truncation correction:** For `version="MD"`, the model applies a truncation correction to account for the constraint that D/MD ≤ 1. This correction divides the CDF by `CDF(1; α, β)` for values where `y ≤ 1`.
- **Vectorization:** The model supports vectorized inputs for `d` and `X_L_ratio`, with proper broadcasting in the numerical integration.
