# Configuration guide for Moss et al. (2022)

Reference: Moss, R., Thompson, S., Kuo, C.-H., Younesi, K., and Baumont, D. (2022). Reverse Fault PFDHA. Report GIRS-2022-05 (Revised 1/17/2024). DOI: 10.34948/N3F595

The Moss et al. (2022) primary surface displacement model predicts principal surface fault displacement exceedance probabilities for reverse faults. It uses gamma-distributed normalized displacement (D/AD or D/MD) convolved with log-normal magnitude scaling.

This class implements the **GIRS-2022-05 report formulation** of the Moss et
al. reverse-fault principal displacement model. For the principal model, the
AD/MD magnitude-scaling coefficients match the values reported in Moss et al.
(2024) Table 3 for the implemented complete/all branches. The practical
differences are that this class exposes report-specific options:
`gamma_mode="global"`, the incomplete MD subset, and the `sigma_type` selector.
Use `Moss2024PrimaryFD` with `source="EQS"` when benchmarking the *Earthquake
Spectra* Table 2 normalized-displacement alpha/beta parameters.

## Model selection

In public jobs, select this class inside an FDHA logic-tree branch with `uncertaintyType="fdhaPrimaryFDModel"`.

## Scope and behavior

- **Supported fault styles:** Reverse only
- **Displacement metric:** Principal displacement
- **Normalization:** D/AD (average displacement) or D/MD (maximum displacement)
- **Statistical distribution:** Gamma distribution (via numerical integration over log-normal XD)
- **Classification:** Single Principal

## Parameters

| Name | Type | Default | Allowed | Required? | Description |
| --- | --- | --- | --- | --- | --- |
| `version` | string | `"MD"` | `"AD"`, `"MD"` | No | Normalized displacement type. |
| `completeness` | string | `"complete"` | `"complete"`, `"incomplete"` (MD only), `"all"` | No | Dataset subset from Table 4.4. `"incomplete"` is only available for MD. |
| `gamma_mode` | string | `"regression"` | `"regression"`, `"global"` | No | `"regression"` uses x/L-dependent linear regression of gamma parameters (Figs 4.3–4.4). `"global"` uses x/L-independent parameters from Eqs 4.2–4.3. |
| `sigma_type` | string | `"recommended"` | `"recommended"`, `"regression"` | No | `"recommended"` uses the revised sigma from Table 4.4 (accounts for dataset-dependence uncertainty). `"regression"` uses the regression standard error. |

## Notes and cautions

- **Style limitation:** This model is for reverse faults only.
- **Gamma parameterization:** Despite the rate notation in the report's Eq. 4.1, `b` is the **scale** parameter. This is verified by Mean(D/AD) = a × b ≈ 1.0.
- **Truncation:** For `version="MD"`, the distribution is truncated at D/MD = 1.0 (displacement cannot exceed maximum displacement by definition).
- **sigma_type fallback:** If `sigma_type="recommended"` but `s_rec` is `None` for the chosen dataset (e.g., MD "all"), the regression sigma is used automatically.
- **Vectorization:** Supports vectorized inputs for `d` and `X_L_ratio`.

## Example FDHA logic-tree branch

```xml
<logicTreeBranchSet branchSetID="bs_primary_fd"
                    uncertaintyType="fdhaPrimaryFDModel">
  <logicTreeBranch branchID="B_MOSS2022_PRIMARY_FD">
    <uncertaintyModel><![CDATA[[Moss2022PrimaryFD]
version = MD
completeness = complete
gamma_mode = regression
sigma_type = recommended]]></uncertaintyModel>
    <uncertaintyWeight>1.0</uncertaintyWeight>
  </logicTreeBranch>
</logicTreeBranchSet>
```
