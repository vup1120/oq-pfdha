# PFDHA Reference Test Suite

Comparison tests between `pfdha` (OpenQuake implementation) and `fdhpy` (reference implementation).

## Structure

```
FDHI_Tests/
├── run_standalone.py              # Quick standalone test (no pytest needed)
├── generate_comparison_dashboard.py  # Generate hazard curve plots & report
├── generate_aleatory_summary.py   # Generate aleatory uncertainty validation report
├── report_utils.py                # Plotting and reporting utilities
├── pytest.ini                     # pytest configuration
├── README.md                      # This file
├── tests/
│   ├── test_simple_reference.py   # Main pytest test suite (exceedance probs)
│   ├── test_aleatory_*.py         # Aleatory uncertainty tests (6 files)
│   ├── conftest.py                # pytest fixtures
│   ├── comparison_helpers.py      # Helper utilities
│   └── __init__.py
├── reports/
│   └── comparison_report.md       # Comparison results summary
├── outputs/                       # Generated by hazard curve dashboard
│   ├── plots/                     # Hazard curve comparison plots
│   ├── comparison_results.csv     # Detailed per-test metrics
│   ├── comparison_summary.csv     # Per-model summary
│   └── comparison_dashboard.md    # Full Markdown report
├── outputs_aleatory/              # Generated by aleatory summary script
│   ├── aleatory_results.csv       # All aleatory test cases
│   ├── aleatory_summary_by_model.csv  # Summary by model+quantity
│   ├── aleatory_dashboard.md      # Markdown dashboard
│   └── *.png                      # Scatter & histogram plots
└── setup/
    ├── requirements.txt           # Python dependencies
    └── setup_environment.sh       # Environment setup script
```

## Quick Start

### 1. Install Dependencies

```bash
# Install fdhpy (reference implementation)
pip install fdhpy
# Or from source:
pip install -e /path/to/fdhpy

# Install pfdha (this repo)
cd /path/to/pfdha
pip install -e .
```

### 2. Run Quick Test

```bash
cd openquake/fdha/test/FDHI_Tests
python run_standalone.py
```

### 3. Run Full pytest Suite

```bash
cd openquake/fdha/test/FDHI_Tests
python -m pytest tests/test_simple_reference.py -v
```

### 4. Run Aleatory Uncertainty Tests

```bash
cd openquake/fdha/test/FDHI_Tests
python -m pytest tests/test_aleatory_*.py -v
```

### 5. Generate Comparison Dashboard (Hazard Curves)

```bash
cd openquake/fdha/test/FDHI_Tests
python generate_comparison_dashboard.py
```

This generates:
- `outputs/plots/` - PNG hazard curve comparison plots
- `outputs/comparison_results.csv` - Detailed per-test metrics
- `outputs/comparison_summary.csv` - Per-model summary
- `outputs/comparison_dashboard.md` - Full Markdown report with embedded figures

### 6. Generate Aleatory Uncertainty Summary (Sigma, Mu)

```bash
cd openquake/fdha/test/FDHI_Tests
python generate_aleatory_summary.py
```

This generates:
- `outputs_aleatory/aleatory_results.csv` - All aleatory test cases
- `outputs_aleatory/aleatory_summary_by_model.csv` - Summary by model and quantity
- `outputs_aleatory/aleatory_dashboard.md` - Markdown dashboard with embedded plots
- `outputs_aleatory/*.png` - Scatter plots and histograms

## Files Description

### `run_standalone.py`
Quick standalone script that runs without pytest. Useful for rapid verification.

### `generate_comparison_dashboard.py`
Generates comprehensive hazard curve comparison reports with:
- Hazard curve plots comparing fdhpy vs pfdha
- CSV/JSON files with detailed metrics
- Markdown summary report

### `generate_aleatory_summary.py`
Generates aleatory uncertainty validation reports with:
- Scatter plots (pfdha vs fdhpy for σ, μ)
- Relative error histograms
- CSV summary by model and quantity
- Markdown dashboard

### `report_utils.py`
Reusable utilities for plotting and report generation.

### `tests/test_simple_reference.py`
Main pytest test file for exceedance probability comparisons.

### `tests/test_aleatory_*.py`
Aleatory uncertainty tests (6 files, one per model):
- `test_aleatory_petersen2011.py` - μ, σ comparisons ✅
- `test_aleatory_kuehn2024.py` - σ_total, μ, σ_mag comparisons ✅
- `test_aleatory_lavrentiadis2023.py` - σ_μ_agg, φ, τ comparisons ✅
- `test_aleatory_youngs2003.py` - skipped (API not exposed)
- `test_aleatory_moss2024.py` - skipped (API not exposed)
- `test_aleatory_chiou2025.py` - skipped (API not exposed)

### `tests/comparison_helpers.py`
Utility classes for comparing fdhpy and pfdha outputs.

### `tests/conftest.py`
pytest fixtures for model loading and configuration.

### `reports/comparison_report.md`
Summary of comparison results and model equivalence status.
