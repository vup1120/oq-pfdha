# Reference

International Atomic Energy Agency. (2025). *Benchmarking Current Practices in Probabilistic Fault Displacement Hazard Analysis for Nuclear Installations*. IAEA-TECDOC-2092, Vienna. DOI: 10.61092/iaea.74us-dn4n.

This benchmark uses Section 7 of TECDOC-2092:

- Table 13 for the Mount Serra tunnel site (`42.749, 13.188`) and Case 3 source-to-site distances.
- Table 14 for Mount Vettore and Norcia fault length, thickness, dip, slip rate, magnitude model, and mean occurrence rates.
- The author-provided workbook for the exact Case 3 fault trace coordinates and incremental occurrence rates used in the source XML.
- Figure 22(c) for digitized IAEA Case 3 total distributed-displacement reference curves.

The final source XML uses the author-provided workbook `PFDHA Benchmarking Study - Norcia - Input data.xlsx` as the source of truth for the fault labels, trace coordinates, and incremental recurrence rates. The spreadsheet labels the sources `MVFS` and `NFS`; their Case 3 incremental rates sum to `4.03281e-4 /yr` and `5.407072e-3 /yr`, respectively.
