# Application to the Norcia Case 3 IAEA Exercise

We demonstrate the logic-tree PFDHA workflow using the Norcia Case 3 exercise from IAEA TECDOC-2092. This example is useful because it contains both principal-fault and distributed-fault-displacement hazard components in a compact source model. The Case 3 configuration adds the Norcia fault to the Mount Vettore fault used in the earlier Norcia Case 1 benchmark, allowing the calculation to represent a two-fault normal-faulting system and to evaluate off-fault hazard at sites located between and near the two traces.

The application inputs are provided in `openquake/fdha/test/benchmark/norcia_case3_iaea/`. The source model file, `source_model_norcia_case3.xml`, contains two characteristic fault sources whose labels, trace coordinates, and incremental recurrence rates are taken from the author-provided Norcia input workbook. The Mount Vettore source is labelled `MVFS` and uses a 47 degree southwest-dipping normal-fault geometry, an 11 km seismogenic thickness, and a characteristic magnitude distribution centered at M_w 6.7. The Norcia source is labelled `NFS` and uses a 50 degree southwest-dipping normal-fault geometry and a 12 km seismogenic thickness. The MVFS occurrence rates are discretized from the Case 3 characteristic Gaussian distribution and sum to 4.03281e-4 /yr. The NFS rates are represented by the workbook incremental Gutenberg-Richter distribution from M_w 5.5 to 6.8 and sum to 5.407072e-3 /yr.

The source-model logic tree, `config_norcia_case3_iaea_source_model_logic_tree.xml`, contains a single branch with unit weight that points to the two-fault source model. The FDHA model logic tree, `config_norcia_case3_iaea_fdha_logic_tree.xml`, contains two equally weighted end branches. The first branch uses the Youngs (2003) principal and distributed surface-rupture and displacement models. The second branch keeps the same Youngs (2003) principal-fault model slots and switches the distributed surface-rupture and displacement slots to the Visini et al. (2025) models. This preserves a runnable Case 3 logic tree while focusing the model comparison on the distributed-displacement component, which is the controlling component for the off-fault Case 3 sites.

The calculation inputs are ordinary INI files. Point-site hazard curves use a `sites = lon lat` entry in the `[geometry]` block, and multiple point sites can be supplied in the same line as comma-separated longitude-latitude pairs. The application curve job, `job_norcia_case3_iaea_curve.ini`, therefore defines the three demonstration sites in one calculation: the principal-fault site PF at 13.278 E, 42.767 N, the Mount Serra distributed site MS at 13.188 E, 42.749 N, and the San Lorenzo distributed site SL at 13.212 E, 42.853 N. The regional map uses a polygonal `region`, a `region_grid_spacing` of 0.005 degrees, and a 100,000 yr return period; this map calculation is defined in `job_norcia_case3_iaea_map.ini` over 13.05-13.35 E and 42.65-42.95 N. Both Case 3 INI files reference the same source-model logic tree and FDHA logic tree, and set `case = case3` so that the distributed-displacement decision logic follows the IAEA Case 3 configuration.

Faulting style is inferred from the source rake during context construction; here both faults have rake -90 degrees, which is classified as normal faulting. A `style` entry can still be supplied inside an FDHA logic-tree `uncertaintyModel` as an explicit model-parameter override, for example to select the Youngs (2003) normal-faulting coefficient subset rather than the all-style subset, but it is not required for this single-style Norcia application.

Figure X compares the computed hazard curves for the principal-fault site PF and the two distributed sites MS and SL. The PF curve is much higher than the off-fault curves because it represents displacement on the principal rupture trace. The distributed-site curves are lower, as expected, and differ from one another because MS and SL sample different positions relative to the Mount Vettore and Norcia fault traces. In this configuration, SL has higher distributed-displacement hazard than MS over much of the displacement range because it lies closer to the mapped distributed-hazard corridor between the two faults.

Figure Y shows the regional total-displacement hazard map for a 100,000 yr return period. The map is produced by computing hazard curves at each grid site and interpolating the displacement corresponding to an annual exceedance frequency of 1e-5 /yr. The highest mapped displacements occur near the fault traces and within the distributed-hazard corridors controlled by the Mount Vettore and Norcia geometries. The fault traces are shown as thin dashed lines so that the displacement field remains visible, and the PF, MS, and SL site markers use the same colors as the hazard curves.

**Figure X.** Fault-displacement hazard curves for the Norcia application sites. The black curve is the principal-fault site PF; the blue and orange curves are the Mount Serra (MS) and San Lorenzo (SL) distributed sites computed with the Case 3 two-fault input model.

**Figure Y.** Total fault-displacement hazard map for the Norcia Case 3 application at a 100,000 yr return period. Colored squares show the displacement interpolated from the mean hazard curve at each grid site. Thin dashed lines show the Mount Vettore and Norcia fault traces, and triangles mark PF, MS, and SL.
